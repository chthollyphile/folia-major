# 动态编排与验收

## 在编码前写下 motion plan

保持简短，但让另一个 Agent 能据此作出一致的设计决定：

| 项目 | 必须明确的决定 |
| --- | --- |
| 意图 | 主角是谁，观众先看哪里，什么关系使它不像通用模板 |
| 输入 | 真正可用的 glyph/word/line 时间、chorus、audio/spectrum；哪些段落判断是推断 |
| 语法 | 乐句如何分组，每类语句的起、承、停、散，下一句如何接力，何时复现主题 |
| 变与不变 | 色光/材质/主风向保持什么；路径形状、词间节奏、近远、组团、速度包络改变什么，为什么改变 |
| 主体绑定 | 发射点与人物/镜头的同一变换；静止图像则明确静态锚点的限制 |
| 空间 | 横竖屏安全走廊、面部禁入区、长词/翻译布局；最后一字唱完前可读 |
| 连续性 | 前句尾迹与后句接力、预卷/间奏/结束、暂停/seek、减少动态效果 |
| 证据 | 用哪些实际歌词与时间段验证，每个关键观察对应连续预览或截图位置 |

有意保持同一轨道的设计（例如唱片槽、书写行）可成立，但需说明审美意图，并从节奏/排版/层次建立变化。不要为通过检查虚构多条路径。受用户明确要求约束时，记录取舍。

## 编排实现原则

先编译 `phraseProgram`，每个条目保存边界、选择理由、seed、空间参数与进入/停留/释放窗。按真实间隔切句；没有元数据时不要把 `index % N` 当作编排。避免相邻无意义重复，但允许乐段回归；合理的 variation 是一个受控的词汇系统。

对单字/词使用分段生命周期：显现 → 唱读 → 延音/聚拢 → 释放 → 消散。运动不需要全程匀速；慢入/轻快弹出/悬停/余波应服务发声意图。时间长的词允许收束位移而继续逐字强调；高速句降低特效密度或增加可用文字空间，不能只加速到看不清。

粒子与镜头分层：歌词要读、装饰可散、镜头维护构图。减少动态效果保留清晰歌词与低幅过渡；不只是降低帧率。用 `frame.time` 和稳定种子求值；不使用随机逐帧累积模拟代替可 seek 动作。

`update(scene)` 只编译与画幅无关的语义/时序并使布局缓存失效。`FoliaScene` 不含字体和屏幕尺寸；同一 scene 下 resize 或字号变化不会自动再次调用 update。在 `render(frame)` 比较布局键（相关文字/行、width/height/dpr、fontFamily/fontWeight/fontScale、字幕对应参数及其他影响布局的开关），仅键变化时重建测量与安全区，其余帧只求附近活动对象。参考 `src/stylePacks/code/example.ts` 的 cacheKey 和夜莺 `lyrics.js` 的 nextKey；字体字重不能漏出缓存键，也不要每帧重测整首歌。

## 四层验收，分别报告

1. **格式**：`folia_style_check_pack` 或 `style:check`；仅 schema/大小有效，不执行包。
2. **运行**：Studio 的验收矩阵、加载错误/超时、字体/封面更新、暂停/seek/销毁、不同歌词与减少动态效果。2→18→2 的相同画面证明确定性，不证明优美。
3. **视觉**：观看连续片段并记录具体时间。横屏/竖屏各看短句、快速句、长词、≥10 秒长音、休止和高潮/弱段。验证发声点不漂移、面部/字不互相遮盖、词尾不早退、留白有效、交接无硬跳。截图辅助比较，不代替连续播放。
4. **适配**：更换歌词和字体、拉大字号、换画幅，确认原本“漂亮”的参数不是只对样例成立。标注性能测试设备和分辨率；帧内 CPU 时间不等于实际播放帧率。

视觉记录的最小条目：`时间段 / 输入与画幅 / 观察 / 证据路径 / pass、revise 或 unobserved / 下一步`。pass 必须对应已经看的证据；未观看项保持 unobserved。对审美取舍的解释应与用户目标一致，不能只说“测试通过”。

## MCP 轨迹诊断的输入

`folia_style_review_motion` 接收实际 renderer 采样或计划轨迹。每个 phrase 标注 label、context（例如 sparse/dense/sustain/rest/chorus）、reason；可选 motif 解释主题复现。samples 是按时间递增的 `{t,x,y}`，x/y 以画幅宽高归一化，t 为该条采样的绝对秒数。应跟踪同一可读文字单元/乐句中心，不把多个字随意拼成一条轨迹。给出 source.kind（rendered/planned）及 artifact 证据路径。分画幅分别调用，建议覆盖至少 4 个乐句和关键状态。

工具会把轨迹重采样至同一相对时间，扣除起点平移，计算形状/速度包络的接近程度，提示重复占比、样本不足、上下文覆盖不足。这样不会因为发射点微移就误判为完全不同。它不会验证 artifact 的视频内容，不分析遮挡、字形、光色，也无法仅凭坐标判断动机是否成立；输入仍需诚实。阈值只是排查线索，慢速低幅作品可合理重复，不要为了消除警告放大抖动。返回始终 `accepted: false`，需要人/Agent 真正观看并记录视觉结论。
