# 个性与样式

这是一套制作标签，按用途分类，不按元素数量、代码量或框架分类，也不代表质量认证。它不改变 Folium 标准清单或宿主选择器。

## 个性：personality

商籁（sonnet）、凝彩（tempera）、绘光（lumiere）、花火（hanabi）、町景（machi）、雾笺（nebbia）是完整视觉设计：主体、场景、材质、镜头、色光与歌词已经组织成关系。夜莺、猫蜂的交付目标也是完整个性。只给普通字幕套壁纸不足以完成这种设计。

## 样式：lyric-template

流光（classic）、心象（cadenza）、云阶（partita）、浮名（fume）、倾诉（tilt）、回环（claddagh）、莫奈（monet）、时计（pendolo）、群唱（cappella）、镜台（diorama）、静止（still）作为可复用歌词模板：研究字词出现、排布、强调、组句、停留与退场。

某些实现同时画封面或几何场景，提炼时将附属元素与歌词行为分开。随机是播放选择，容器入口也不是模板；未知模组不可擅自标为成熟个性。

## 选用与移植

1. 用 `folium_catalog` 和 `folium_reference` 看当前源码。在设计说明中记录目标 kind、主要参考及保留/改造的行为；这些字段只用于 MCP 和制作说明，不写入 `mod.json`。
2. 类别与释放语法是两条轴。个性和样式都可以采用逐字、逐句或独立字词组句；类别不能替代动作决策。
3. 从 `folium-aurora` 和 `folium-52hz` 学习标准注册、宿主时钟与生命周期。内置 React/Three.js 代码不能作为可直接导入的宿主私有模块；转换成公开 `FoliumStageContext` 驱动的相对模块。
4. `npm run folium:new -- <folder>` 提供标准起点，不等于十一种内置样式的复刻。自带库放入模组目录并附许可证。
5. 阿拉伯等连写语言保持整段塑形，必要时用遮罩实现逐字；不把拆散字母称为正确效果。

## 验收

- 样式重歌词行为与复用；个性还要检查主体、空间、材质、镜头和情绪。
- 出生、输送、停驻及 N+2 分别验证。夜莺真实字形从女孩附近流出；猫蜂旧字不得跟随移动发射者。
- 空白行不推进 N+2，触发取相应模式的真实首字出现时刻；已驻留旧字不能截断或被重新排布。
- 换字体、字号、画幅、歌词、暂停与跳转后仍成立。格式检查与诊断均不能证明审美合格。
