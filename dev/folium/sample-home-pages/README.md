# 首页组件插槽示例

本分支的实验接口 `home.pages`，清单必须显式选用；稳定 Folium 1.4 契约不变。旧 `homeTabs` 示例不兼容。

无需账号、网络和权限。把本目录文件压成 ZIP，在模组页面安装并启用。

1. 网格首页原生导航末尾出现记事图标，悬停或键盘聚焦时用 300ms 展开“记事”文字。墙面首页原生直达入口（如“我喜欢的音乐 / 云盘”）下方显示居中的“记事”；缩短窗口后移入“更多”，变为与相邻菜单按钮一致的图标和左对齐文字，拉高后恢复。未登录仍能使用。
2. 点击打开占满首页的离线记事页，输入中文、空格、换行，Tab/Shift+Tab 在组件内正常移动，不切原生来源。
3. 点击“记录动作”，检查计数与模组日志；草稿仅在本次启用期间保留，不写磁盘。
4. 用页面内“返回资料库”或宿主返回键退出，原生来源、条目顺序和浏览位置保留。命令面板可搜索“记事”重新打开。
5. 页面打开时停用模组，页面与导航消失，回到原生首页；日志包含卸载记录。重新启用后可再次打开。

导航与正文分别隔离在 ShadowRoot 中。示例展示挂载、输入、动作和清理，不提供重排、替换或隐藏任何原生条目的接口。

2.0.4 的导航样式和图标均由示例提供：使用 `folium.ui.icon` 加载图标，失败时保留可见后备图标，卸载后不再更新 DOM；通过 ShadowRoot 内 `:host-context([role="menu"])` 适配通用菜单，不新增宿主按钮模板或位置接口。

墙面列中的记事按钮通过宿主提供的 `--folium-home-shortcut-width` 跟随原生快捷入口组的实际宽度，与“我喜欢的音乐”“云盘”的背景左右对齐。没有原生快捷入口时回退为可用列宽；更多菜单仍使用菜单内的宽度。列内和菜单内的相邻入口均保持 2px 间距。
