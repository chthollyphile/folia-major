播放会话 API 验收（离线）

安装后，在命令面板搜索“播放会话验收”。所有音源都是本机生成的轻声测试音，无需登录。
先点“准备私人队列”，然后“建立会话并播放 B”。使用宿主播放条、键盘或遥控验证：
- Ctrl + 左/右方向键切换上一首/下一首；macOS 使用 Cmd + 左/右方向键。
- 在播放页单独按左/右方向键，向后/向前跳转 5 秒，保留暂停状态。
- 点击聚焦示例按钮后，Enter 或 Space 应各触发一次该按钮；Tab / Shift+Tab 仍切换宿主面板标签，Escape 仍可关闭面板。
- 暂停/恢复只控制本机，不产生会话意图。
- 切歌/跳转会写入面板日志。禁止权限后，相应原生按钮应不可用，键盘也不能绕过。
- 释放会话和停用模组后，原私人队列恢复，播放停止。
- 慢请求测试请在全新测试配置中首次启用模组后优先进行，再测试其他播放按钮：“加载慢音源后立即退出”之后等 5 秒，不应突然开始播放；日志应显示 cancelled。若先前已缓存音源并显示 source-committed，本次不能证明慢请求被取消。
- “下次意图抛错”再点击下一首，会话应自动释放，模组诊断记录预期错误。
- “清空媒体，保持会话”清除当前歌曲和音源，但不释放控制权。此时播放/进度条不可用，仍可通过 Ctrl/Cmd + 左右方向键或浮动播放条的上一首/下一首请求新曲目；也可点击“建立会话并播放 B”重新加载 B。它不会清空队列列表。

测试不同模组争抢控制权时，可以复制此示例并更改 id 和 provider ID。
该示例只用 Folium 公开/实验接口；不读取宿主 DOM，也不修改私人队列条目 UI。

测试音源与歌词无需联网；若宿主开启了“自动寻找最佳歌词”，仍会执行其正常搜索流程。
完全离线验收时，可在设置中暂时关闭该选项。
