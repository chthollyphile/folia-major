# 音效控制台样例（sample-equalizer-console）

需要 Folium 1.7（桌面版）。在模组的设置里加一个「音效控制台」分区，经 `folium.equalizer` 读写宿主的图形均衡器：
显示此刻听到的均衡器，切到一个内置音效、换上这个模组自己的曲线、再撤下，以及一个「按歌自动施加」开关，演示模组怎么给用户让步。

权限：

- **读不需要权限**：`folium.equalizer.getState()` 和 `equalizer.changed` 事件谁都能用。
- **写需要 `equalizer.control`**（`setMode`、`applyCurve`、`releaseCurve`），所以 `mod.json` 声明了它。启用确认窗口和模组面板会为它写一句
  「会改写你的音效设置」。声明了这个权限的清单在 Folium 1.6 的宿主上整份被拒；只读的模组不声明它，就能在 1.6 上装。

不用实验接口，不需要 main 入口，不存数据（「按歌自动施加」是设置分区里的一个开关，值由宿主保管）。

## 安装

这个目录**没有签名**，开发版也**不会自动扫描** `dev/folium/`，需要手动安装（装好后在模组面板里显示为「未验证」）：

- **打 zip 拖进去**：把整个目录打成 zip，拖到模组面板上。`mod.json` 在 zip 里唯一的顶层文件夹里也可以：

  ```powershell
  Compress-Archive -Path dev/folium/sample-equalizer-console -DestinationPath sample-equalizer-console.zip
  ```

- **复制到用户模组目录**：模组面板右上角「打开模组目录」，把 `sample-equalizer-console` 目录复制进去，再点「重载」。
- 开发时也可以临时复制到仓库的 `mods/` 下，享受开发目录「改了文件不用重新确认」的豁免；但不要提交到那里：`mods/` 里的模组必须带官方签名，
  `test/unit/mod-system/sampleMods.test.ts` 会失败。

然后在模组面板里启用「音效控制台（样例）」并确认：确认窗口里会多一句「会改写你的音效设置（equalizer.control）」。

## 试用

在「设置 → 模组」里展开「音效控制台（样例）」，看它的设置分区。

1. **当前均衡器**：模式（内置音效、用户的自定义栏位、或某个模组的曲线）、总开关、10 段增益（下面一行是各段频率）、
   声音经不经过宿主的音频（`hostPlaysAudio`，外部 Stage 播放时为否）、能不能写（`writable`，音频效果器开着时为否），
   以及最近一次 `equalizer.changed` 来自谁。在音频效果器里换个预设、拨一下总开关、打开再关上它，这几行都跟着变。
2. **写入**：
   - 「切到低音增强」是 `setMode({ kind: 'preset', id: 'bass' })`：曲线和效果链一起换，和命令面板的「音效：低音增强」一样；
     但**不打开总开关**，总开关关着时写入照常、只是听不到。
   - 「施加微笑曲线」是 `applyCurve([4, 3, 1, 0, -1, -1, 0, 1, 3, 4])`：模式变成「本模组的曲线」。
     打开音频效果器看：上方写着曲线来自这个模组，没有预设亮着，频段和效果区是只读的，有「换回我的音效」「存进自定义 1 / 2」三个按钮。
     你的自定义栏位一个字节都没改；「存进自定义 2」才会把这条曲线（加上你当前的效果链）写进自定义 2。
   - 「撤下」是 `releaseCurve()`：在位的是本模组的曲线时撤下、回到你原来的音效；不是的话什么都不变。
   - 宿主的提示：这个模组**接手别人定下的音效**时（你刚在音频效果器里换过预设、在命令面板里选过音效，或者在位的是别的模组的曲线），
     宿主弹一条提示，写明是哪个模组把音效切到了哪里、或换上了它的曲线。它接着自己上一次的写入再写就不再提示：先按「切到低音增强」
     再按「施加微笑曲线」，只有第一下弹；按歌自动施加的模组也只在接手的那一次提示，不会每首歌一条。「撤下」不弹，它是回到你自己的音效。
   - 每次写入都显示宿主的回答：「已接受」，或者拒绝的原因。一秒内先后按「切到低音增强」和「施加微笑曲线」，第二下得到 `rate-limited`；
     连按两下「施加微笑曲线」，第二下却是「已接受」：写的和现在一样，没有变化的写入从不被拒，也不计数。
     音频效果器开着时，会改变东西的写入得到 `panel-open`（下面的「按歌自动施加」演示怎么在窗口关上之后补写）。
3. **按歌自动施加**：打开开关，换一首歌，模组按这首歌换上一条曲线（同一首歌总是同一条）。然后：
   - 在音频效果器里点一个预设、或者在命令面板里选一个音效：`equalizer.changed` 的来源是 `user` / `command`，开关自己关掉，下面写着「你调过音效了，自动施加已停」。
     要它继续，自己再把开关打开。
   - 打开再关上音频效果器、进出外部 Stage：来源是 `host`，不算你调过音效，开关不关。
   - 换歌时音频效果器正开着：这首歌的曲线被拒 `panel-open`，下面写着「等音频效果器关上再写」；关上窗口的那次 `equalizer.changed`（`writable` 变回 true）一到，就补写这一条。
4. **停用这个模组**：在模组面板里停用它，声音回到你自己的音效，音频效果器里写着这个模组的曲线「暂未生效」，有「丢弃这条曲线」；
   重新启用后曲线自己回来，不需要模组再施加。重载模组不影响声音，只要它不用重新确认：没改文件，或者改的是放在开发目录（仓库的 `mods/`）里的副本。
   照上面的装法放在用户模组目录里的，改了文件再重载就要重新确认；确认之前它算停用，曲线和停用时一样暂停，确认之后回来。

## 写模组时要记住的

- 只有写需要权限；面板开着时会改变东西的写入被拒，关上后有 `equalizer.changed`，按 `state.writable` 补写，不要轮询。
- 自动施加要让步：来源是用户、宿主命令或别的模组时停下，`host` 和你自己的写入不算。在那之后再把曲线放回去，就是在覆盖用户的选择。
- 每次改变东西的写入都会存盘，目前每个模组一秒一次、一分钟 20 次：写定下来的结果，不要拿它做动画。
- 智能过渡（automix）里能听到两首歌叠在一起时，宿主把模组的变化推迟到过渡结束才放进声音里，`getState()` 立刻就报新的。

接口的完整说明见规范（`mods/README.md`）里的「folium.equalizer（1.7）」和 API 参考的 `FoliumEqualizerService`。
