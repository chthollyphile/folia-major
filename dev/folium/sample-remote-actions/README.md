# 遥控附加按钮示例

需要实现实验接口 `remote.actions` 的宿主；稳定 Folium 版本仍为 1.5。
将此目录内三个文件压成 ZIP，在模组管理器安装并启用，再打开独立遥控窗口。

模组只在主窗口普通 `default` 入口注册动作，宿主绘制追加按钮并将点击送回主窗口执行。
原生播放、循环、收藏、窗口及录制控件的位置和执行路径保持原样。不加载远程模组脚本，没有 Node 入口、RPC、输入框或任意组件挂载。

- 播放一首歌后，连续点击“示例点赞”，或 Tab 聚焦后按 Enter/Space：该歌曲的计数增加。鼠标悬停或键盘聚焦时显示圆角计数。
- 切到另一首歌后，计数独立；无歌曲时点赞禁用。此动作使用默认 `track` 范围，旧歌曲的迟到点击失效。
- “停止示例试听”使用 `session` 范围，即使切歌或无歌曲仍可执行；点击后禁用。这里只更改示例状态，不会停止宿主歌曲或发送真实消息。
- 执行日志在模组日志中以 `remote.actions demo` 开头。示例完全离线，不需要真实账号。
- 停用/卸载后追加区消失，重新启用恢复初始计数；无需重开遥控窗口。
- 检查明暗主题、450×230 窗口、录制页与透明控制页。追加按钮只在播放页显示，无贡献时不占布局；更多按钮在追加区内部滚动。

`actions({ song, state })` 返回当前按钮，`handle.invalidate()` 通知宿主重新读取。`label` 使用 FoliumLabel 语言映射，宿主按遥控窗口语言翻译。模组无法重排、隐藏或替换原生按钮。
