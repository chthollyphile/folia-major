# 播放器布局避让示例

2.1 示例需要带 `FoliumStageContext.getLayout()` 与四向 `insets` 的 `player.layout` 实验接口宿主（基于 Folium 1.5）。
旧 2.0 示例使用的独立 `folium.experimental['player.layout']` 服务已移除；旧 1.x 快照也不是本版契约。
打包本目录为 ZIP 后通过模组管理安装并确认启用。无账号、网络请求或发送动作。

清单 opt-in `experimental: ["player.layout"]`；完整示例 UI 挂在已有
`stageLayers` 的 `app.overlay` 槽位，通过 `ui.stage` 权限追加。布局只读
`mount(container, ctx)` 中的 `ctx.getLayout()`，用已有 `ctx.subscribe()` 接收通知，不查询宿主 DOM，
也不重排、隐藏或替换原生控件。字体、圆角、颜色和避让算法全部由示例模组提供。

人工检查：

1. 进入播放页：左下聊天避开返回按钮完整 120×120 唤出区、底栏和正在播放卡片，右上气泡避开真实相交的控件。
2. 打开未到顶的右侧面板：右上气泡有足够空间时保持原位；真正相交时才移动。
3. 返回按钮隐藏后，鼠标移到预留的左上唤出区域：按钮出现且可点。打开设置弹窗或命令面板后再移到左上角，
   背后的返回按钮不应被唤出；模组自己的内容也不会把鼠标移动穿透到播放页。
4. 调整窗口大小、底栏高度、侧栏和 Toast：模组组件跟随几何更新，原生控件位置不变。桌面自定义标题栏启用时，
   示例避开整条宽、56px 高的标题栏预留；原生窗口边框和浏览器没有这一条预留。
5. 切到首页：快照为空，示例隐藏。停用模组：组件、订阅与无使用者的布局观察器消失；重新启用：只恢复一份。
6. 设置预览、OBS、导出中 `ctx.getLayout()` 为 `null`；清单未声明 `player.layout` 时也为 `null`。

`bounds` 和障碍物矩形使用视口 CSS 像素，原点为视口左上角，与 `getBoundingClientRect()` 一致；
障碍物已裁剪到 `bounds`。示例先扣除四向 `insets` 安全预留，再对每个 `rect` 独立检查相交；
不依赖内部组件 id、障碍物数量、顺序或 role，也不把多个相同 role 的面板区域合并成大框。

只有选用该实验能力的上下文订阅才启动测量，单独读取不会启动；没有订阅或首次测量前返回 `null`。
示例先订阅再读取，并在快照为空时隐藏组件。几何通知合并到 80ms；
`ctx.subscribe()` 还可能因主题等其他状态变化触发，示例比较快照引用避免重复布局。
这不是逐帧动画同步接口。示例可因可用区域太小而隐藏组件。
