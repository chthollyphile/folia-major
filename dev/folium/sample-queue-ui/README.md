# 队列组件插槽离线示例（2.0.2）

需要支持组件版 `experimental: ["queue.ui"]` 的宿主。旧 1.0.0 动作描述示例不兼容此实验接口，请替换。

启用后，在宿主队列添加自己的歌曲，分别打开播放页面板、命令面板、墙面队列浮岛和 Lattice 展开海报。
本例不生成或替换队列，不联网、不发送消息、不改变播放控制权。

- 推荐者文字、点赞图标、圆角计数背景和同步按钮均由本模组挂载，样式位于 `components.mjs`。
- 点赞只增加本地示例计数；相同下标在各处同步，同一歌曲的不同下标独立。重新启用时计数重置。
- 计数统一使用圆角背景，悬停或键盘聚焦时显示。命令面板标题区仅追加同步按钮，利用原有上下留白，不撑高工具栏。
- 同步按钮只记录点击。日志通过 `folium.log.info` 输出 surface、index、歌曲及计数。
- Enter/Space 可激活按钮；停用后移除组件并清理订阅，恢复原生布局。
- 修改模组 CSS 或将 mount 改成其他 DOM/组件后重新加载模组即可改变 UI。宿主只负责隔离容器及追加位置。
