# 第一个模组：从零到跑起来

这一页带你在本仓库的 `mods/` 目录里做出一个能跑的模组，用两条命令和一个类型文件。读完大约十分钟。

写完第一个之后，往下读的顺序是：[模组开发与贡献指南](contributing.md)（怎么写好、怎么发布）、[API 参考](api.md)（每个接口，开头有[注册表一览](api.md#注册表一览)）、[Folium 规范](../../mods/README.md)（规则）。

## 1. 准备

```bash
npm install
npm run dev:electron
```

应用打开后，到「设置 → 模组」打开最上面的「模组系统」开关。这个开关默认是关的；关着的时候不加载任何模组。

## 2. 生成一个起点

```bash
npm run folium:new my-first-mod
```

它新建 `mods/my-first-mod/`，里面两个文件，每个模组都是这两个：

- `mod.json`：模组的名字、版本、入口文件。文件夹的名字就是模组的 id，只能用小写字母、数字和 `-`。
- `client.mjs`：模组的代码。它默认导出 `activate(folium)`，应用启用模组时调用一次。生成的这份登记了一个歌词动画，居中显示当前这一行歌词。

同名的文件夹已经在的话，这条命令什么都不写。

## 3. 检查

```bash
npm run folium:check my-first-mod
```

它只读文件，不运行模组。它查的是：

- `mod.json` 能不能被应用接受（用的就是应用自己的校验代码，报错的话和应用里那一行显示的一样）；
- `mod.json` 里写的文件在不在，`client.mjs` 有没有默认导出；
- 代码里用到的 `folium.registries.<名字>` 有没有这个注册表，它要的权限有没有写进 `mod.json`；用到的实验接口有没有在 `mod.json` 里选用；
- 这个文件夹能不能被应用校验，带不带官方签名、签名还对不对。自己写的模组是「没有签名」，这不算问题。

它查不出来的：`activate` 和 `mount` 运行起来会不会出错、会不会留下没停掉的东西。这些要在应用里看（第 6 节）。

## 4. 在应用里跑起来

1. 「设置 → 模组」里点「重载」，列表里出现 `my-first-mod`。
2. 打开它那一行右边的开关，在弹出的确认窗口里确认。
3. 打开歌词样式的设置，在「歌词动画」里选 `my-first-mod`，放一首有歌词的歌。

## 5. 改代码

改 `mods/my-first-mod/client.mjs`，回到「设置 → 模组」点「重载」，新代码就生效了。放在仓库 `mods/` 目录里的模组，在开发版里改了文件不用重新确认。

生成的代码里有这样一段：

```js
draw();
ctx.onChange(draw);
```

`ctx.onChange` 是 `ctx` 上的现成函数：换行、暂停、换主题、改显示设置时，应用替你调用 `draw`；这个歌词动画被换掉或模组被停掉时，应用替你停掉它，不用自己写取消的代码。同一类的还有 `onLyricTime`（跟着歌词时间走）、`onFrame`（每帧）、`onResize`（容器大小变了）、`every`（定时）、`onDispose`（结束时清理），每个的说明和例子在[现成的函数](contributing.md#现成的函数)。

## 6. 出错了看哪里

「设置 → 模组」里展开你的模组那一行：

- 「界面代码出错」下面每个出错的地方一行，写着出错几次、最近一次的时间和原因；
- 「用了多少时间」写着启动用了多少秒、运行时每秒约用多少毫秒；
- 模组的代码出错时，应用顶上会提示一次是哪个模组的哪一种条目出了错。

要看完整的报错，打开开发者工具的控制台。

## 7. 编辑器里的提示

`mods/folium.d.ts` 是 Folium 全部公开类型的一份文件，从契约生成，不引用任何别的文件。生成的 `client.mjs` 开头已经指到它：

```js
/** @typedef {import('../folium').FoliumClientApi} Folium */

/** @param {Folium} folium */
export default function activate(folium) { /* ... */ }
```

这样在 VS Code 这类编辑器里敲 `folium.` 就有补全和每个成员的说明，不需要构建，也不需要装任何东西。这几行注释只给编辑器看，运行时不起作用。

模组不在本仓库的 `mods/` 目录里时，把 `mods/folium.d.ts` 拷到模组文件夹的旁边（不要放进模组文件夹里面，里面的每个文件都算模组的内容），再把注释里的路径改成拷过去的位置。

改了契约（`src/mods/folium/contract.ts`）的维护者要重新生成这个文件：`npm run folium:types`。忘了的话单元测试会失败。
