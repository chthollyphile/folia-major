# 风格包的设计基准

分析基于当前内置代码，并在实际播放器以同一测试歌切换凝彩、花火、绘光、商籁观察切句和镜头。内置设计是完整的动态歌词舞台。

| 风格 | 设计特征 | 包所需表达能力 |
| --- | --- | --- |
| 凝彩 Tempera | 字词层级、色块反色、网点、几何构图、纵向镜头交接、段落转场，间奏持续运动 | 歌词编译为镜头；布局和镜头分离；遮罩合成 |
| 花火 Hanabi | 字底形状、逐字入场和演唱强调、烟花粒子、贴纸拼贴、上升和旋转 | 每字时间/锚点；图形跟随文字；全局镜头 |
| 绘光 Lumiere | 天光/窗隙/棱镜等光位，光束、雾、浮尘、线稿；歌词被点亮并换位 | WebGL/着色器、灯光后处理、多层合成 |
| 商籁 Sonnet | 编辑式排版、文字冲击、碎片拼贴、遮罩、海报构图，段落语义驱动镜头 | 可替换排版算法、段落分析、运镜/转场生命周期 |

入口：`src/components/visualizer/tempera/README.md`、`sonnet/sonnetProgram.ts`、`hanabi/types.ts`/`catalog.ts`、`lumiere/catalog.ts`/`types.ts`。

原先 v1 的固定封面＋整行歌词＋简单摆动无法承载这些特征。v2 把契约放在数据输入和生命周期，允许作者自行写渲染算法。PRISM 示范逐字歌词、三种构图、几何运镜与确定性跳转，并非对所有内置特效的复刻。

## 从视频提炼规则

1. 画面组织：字号与重心、横竖排、层级、遮挡。
2. 时间组织：动作由字/句/节拍中的哪种信号触发；准备、到位、保持、离场各多长。
3. 镜头：世界还是单字在移动/旋转/缩放；上下镜头如何交接；间奏如何处理。
4. 材质：粒子、光束、网点、残影、色差；哪些复用素材，哪些程序生成。
5. 泛化：换歌、长歌词、多语言和竖屏后规则是否成立。

取帧提供静态证据与时间点；运动曲线、瞬时遮罩和节拍关系需结合原视频观察。每项写明“观察”“推测实现”“验收方法”。验收包括连续运动、跳转与新歌词，不能只比较一张相似截图。
