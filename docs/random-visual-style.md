# 手动随机样式

播放器外观区、外观设置和歌词调参台共用「全随机」开关与「随机样式」按钮；命令面板也提供相同动作。

默认只随机歌词动画模式及其参数，通用字体、字号、透明度、独立背景和字幕设置保持原值。开启「全随机」后，同时随机通用设置和独立背景参数。范围开关会记住选择，支持外观配置导入导出与设置同步；切换范围本身不会改变画面。

点击「随机样式」会生成并保存整组配置，切歌、暂停和重启继续沿用。再次点击随机、修改特定设置或应用其他外观配置才改变结果；手动修改只更新指定字段。该动作会关闭已有的「每首歌随机歌词动画」选项，防止下一首覆盖刚刚选定的样式。

字幕设置不参与随机；继承歌词字体的字幕仍会随歌词字体显示变化。已有上传字体、图片和 URL 资源继续保留；随机只在合法参数及已有资源之间选择。减少动态效果和壁纸模式限制可选动画为较平缓的模式。

收藏预设与命名将在后续 PR 中接入，本次仅提供手动随机。
